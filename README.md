## Структура репозитория

```
Data-structures-and-algorithms/
├── README.md
├── ЛР1/                # Анализ временной сложности алгоритмов
├── ЛР2/                # Рекурсия и линейные структуры
├── ЛР3/                # Простые сортировки, QuickSort
├── ЛР4/                # MergeSort, Counting/Radix/HeapSort
├── ЛР5/                # Бинарное дерево поиска
├── ЛР6/                # Поиск: линейный, бинарный, интерполяционный
├── ЛР7/                # Поиск подстрок
└── ЛР8/                # Хеш-таблица
```

Каждая папка `ЛРn/` содержит исходный код решения, при необходимости — отчёт и данные для тестирования, в соответствии с требованиями КИМ соответствующей лабораторной работы.
